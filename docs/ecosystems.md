# The supported ecosystems

Read this page if you want to know which projects Heidi Fix can scan and
fix.

## The ecosystems

The scan finds the dependencies of Maven, Gradle, Node.js, Python, Ruby, PHP
Composer, Go, Rust Cargo, .NET, and other ecosystems.

Heidi Fix gives full support to Maven, Gradle, and npm. For another
ecosystem, give the build commands in the user file. See
[The build commands](configuration.md#the-build-commands).
